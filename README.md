# Magic Base Defense

A 3D first-person magic-based base defense game developed in **Unity 6**.

The player must defend their base against increasingly difficult waves of enemies using magical spells, protective wards, and a resource-management system built around Ambient Energy (AE).

This is a personal development project focused on experimenting with gameplay mechanics, programming, and game systems.

## Features

### Currently Implemented
- **First-person movement** — Player movement and camera controls.
- **Spellcasting** — Projectile-based magical attacks.
- **Enemy AI** — Enemies that pursue and attack the player's base.
- **Wave system** — Progressive waves of enemies.
- **Wardstone placement** — Construct magical wards by positioning wardstones around the base.
- **Ward efficiency** — Wardstone positioning affects the efficiency of the ward network.
- **Ambient Energy (AE)** — Generate AE through wardstone connections and spend it on additional wardstones.
- **Placement preview** — Visual feedback showing valid and invalid wardstone positions.
- **HUD** — Displays information such as base health, current wave, and AE resources.

### Planned Features
- Ward upgrades and progression
- Additional spells and enemy types
- Expanded ward mechanics, including defensive barriers
- Multiple levels and environments
- Victory conditions and level progression
- Additional visual effects and UI improvements

## Ward System

The ward system is a central mechanic of the game.

Players place wardstones around their base to establish magical defenses. Once enough wardstones are connected, the ward becomes active and begins generating Ambient Energy.

AE generation depends on the number of wardstone connections and their placement efficiency. Players can use this energy to expand and eventually upgrade their defenses.

The long-term goal is to create a flexible system that rewards strategic ward placement and resource management.
